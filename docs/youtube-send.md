# Sending a reviewed YouTube Live chat message

The YouTube listener reads public chat with `YOUTUBE_API_KEY`. Posting uses a separate broadcaster OAuth access token in `YOUTUBE_OWNER_TOKEN`. Enable YouTube Data API v3 for your Google Cloud project, create an OAuth client and authorize the broadcaster account for `https://www.googleapis.com/auth/youtube.force-ssl` or `https://www.googleapis.com/auth/youtube`. Supply a current access token to the process executing `send`. The program does not store tokens in SQLite or refresh expired tokens. [Google OAuth guide](https://developers.google.com/youtube/v3/guides/authentication)

1. Start `python3 -m socialbot listen youtube --channel YOUR_LABEL --live-chat-id YOUR_ACTIVE_CHAT_ID` on the broadcaster's active stream.
2. Inspect `python3 -m socialbot drafts --status pending`. The approved text must fit in a single message of 1–200 characters.
3. Run `python3 -m socialbot approve DRAFT_ID`, then `python3 -m socialbot send DRAFT_ID` when ready to post. The command sends from the authorized broadcaster to the chat ID saved from the live event. The local room label never decides the destination.
4. Look for the YouTube message ID in the send output or draft record. A YouTube Live chat message is a standard room message. Google supplies no parent-message field for this operation. [Google LiveChatMessages.insert](https://developers.google.com/youtube/data/live/reference/rest/v3/liveChatMessages/insert) · [YouTube Live Chat limits](https://support.google.com/youtube/answer/15270973)

Before posting, the adapter locates the exact saved chat among the active broadcasts, verifies that its lifecycle is `live`, and cross-checks the broadcast channel against `channels.list(mine=true)` for the same bearer token. It then makes one insert request and checks the returned message ID, chat ID and author channel. An ownership or credential check failure leaves the approved draft available for correction. Explicit rejection records failure. A lost or ambiguous response records uncertain delivery and will not resend automatically. [Google LiveBroadcasts.list](https://developers.google.com/youtube/data/live/reference/rest/v3/liveBroadcasts/list) · [Google Channels.list](https://developers.google.com/youtube/data/reference/rest/v3/channels/list)
