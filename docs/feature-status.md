# Coverage of the creator-growth brief

| Requested workflow | Delivered path | Current boundary |
| --- | --- | --- |
| BIGO public chat and keyword responses | BIGO Chat History JSON import and creator-selected local POST from Social Stream Ninja, rule matching, editable response queue | Creator forwards the message and can copy the response. Direct BIGO posting requires verified broadcaster access and a scoped delivery interface. |
| Live chat across platforms | Twitch and YouTube listeners, Chaturbate room Events API, signed Kick, Tango and Fanvue receivers, SSN public-chat inputs, signed creator bridge | Connectors expose different data. Tango and Fanvue persist aggregate receipts. Kick uses ephemeral suggestions. Full table is in the README. |
| Greetings, recognition and gift acknowledgments | Room-scoped viewer memory, entry and gift templates, unit-specific tier rules, native Chaturbate V2 notices and configured regulars | The Python engine recognizes repeat entries and supports native Bits and token thresholds. Native Chaturbate tip notices use a configurable room cooldown and generic acknowledgment. |
| AI co-host and editable wording | Local Ollama, creator persona, automatic drafting for recent unanswered questions, creator-written reply variants, live rule reload and draft editor | Model output enters review. Reviewed messages have delivery on Twitch and on the broadcaster's verified YouTube live chat. |
| Timed announcements and creator links | Per-room schedule, quiet-room and recent-activity checks, creator-approved link campaigns, affiliate disclosure, optional timed Twitch publishing | Other supported native rooms get review/copy entries. Imports and past chat history cannot establish a currently live room. |
| Fan follow-up and pruning | Explicit room opt-in, withdrawal, welcome and follow-up review queue, expiry and creator revocation. Follow-back requests have a review list, cancellation, expiry and manual completion. | Automatic Telegram welcomes run after a viewer initiates a private conversation. The other account's follow/unfollow controls remain with the creator. |
| Niche discovery | Official Twitch live directory query scoped by category and optional language | Discovery returns room links. Posting promotional comments to other creators' rooms and automated account following are outside the implementation. |
| Creator dashboard and fleet | Draft review/edit, rules and fleet config forms, channel/account metrics, regulars, local database comparison and worker heartbeats | State is local. Fleet configuration changes apply on supervisor restart; event rules reload as activity arrives. |
| Alerts, watchdog and deployment | Twitch/YouTube/Chaturbate worker supervision, persistent event cursor, Discord/Telegram operator notifications, native bootstrap, Docker Compose and CI | Third-party account grants, HTTPS callback registration and tests against the creator's accounts are deployment steps. |
| More cam services | Creator-forwarded public chat for Stripchat, CAM4, CamSoda, BongaCams, Fansly, MyFreeCams and LiveJasmin, plus Chaturbate's broadcaster interfaces | An operator-defined platform label accepts a creator-supplied normalized feed. A label does not imply a native platform connector. |
| Multi-account anti-detection tools | Multi-room operation uses independent credentials, bounded request rates and documented interfaces | CAPTCHA or fingerprint evasion, proxy rotation to avoid enforcement, and interception of private platform traffic are outside the implementation. |

The reproducible offline checks exercise the contracts, receipt verification, rollback and deduplication for these workflows. A live account test is a separate acceptance step for each connected service.
